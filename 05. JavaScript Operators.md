# 1. Introduction to JavaScript Operators

JavaScript operators are special symbols or keywords used to perform operations on variables and values.

Operators help us perform different tasks, such as:

- Performing mathematical calculations.
- Comparing two values.
- Checking multiple conditions.
- Assigning values to variables.
- Making decisions in programs.
- Working with strings and data types.

### Example

```javascript
let a = 10;
let b = 20;

let result = a + b;

console.log(result);
```

**Output:**
```text
30
```

**Explanation:**

- `let a = 10` creates a variable.
- `let b = 20` creates another variable.
- `a + b` adds both numbers.
- `console.log()` displays the result.

JavaScript provides several types of operators.

## 2. Types of JavaScript Operators

JavaScript operators are commonly categorized into the following types:

| No. | Operator Category | Description |
|---|---|---|
| 1 | Arithmetic Operators | Perform mathematical calculations |
| 2 | Assignment Operators | Assign values to variables |
| 3 | Comparison Operators | Compare two values |
| 4 | Logical Operators | Combine multiple conditions |
| 5 | Increment and Decrement | Increase or decrease values |
| 6 | Ternary Operator | Make decisions using conditions |
| 7 | String Operators | Combine strings |
| 8 | Typeof Operator | Identify data types |
| 9 | Comma Operator | Evaluate multiple expressions |

### Example 3: Difference Between Pre-Increment and Post-Increment

This is an important JavaScript concept.

**Post-Increment:**

```javascript
let x = 10;

let result = x++;

console.log("Result:", result);
console.log("X:", x);
```

**Output:**

```text
Result: 10
X: 11
```

**Explanation:**

- First, the current value of `x` is assigned to `result`.
- After that, `x` increases by 1.

**Pre-Increment:**

```javascript
let x = 10;

let result = ++x;

console.log("Result:", result);
console.log("X:", x);
```

**Output:**

```text
Result: 11
X: 11
```

**Explanation:**

- First, `x` increases by 1.
- Then the updated value is assigned to `result`.

# PART 4: LOGICAL OPERATORS

## 31. What Are Logical Operators?

Logical operators are used to combine multiple conditions or reverse a Boolean condition.

JavaScript provides three primary logical operators:

| Operator | Name | Description |
|---|---|---|
| `&&` | Logical AND | Both conditions must be true |
| `||` | Logical OR | At least one condition must be true |
| `!` | Logical NOT | Reverses a Boolean value |

## 32. Logical AND (&&)

Returns true when both conditions are true.

**Example:**

```javascript
let age = 25;
let hasLicense = true;

let result = age >= 18 && hasLicense === true;

console.log(result);
```

**Output:**

```text
true
```

Explanation:

- `age >= 18` is true.
- `hasLicense === true` is true.
- Both conditions are true.

Therefore, the result is true.

### AND Truth Table

| Condition A | Condition B | Result |
|---|---|---|
| true | true | true |
| true | false | false |
| false | true | false |
| false | false | false |

## 33. Logical OR (||)

Returns true if at least one condition is true.

```javascript
let isWeekend = false;
let isHoliday = true;

let result = isWeekend || isHoliday;

console.log(result);
```

**Output:**

```text
true
```

### OR Truth Table

| Condition A | Condition B | Result |
|---|---|---|
| true | true | true |
| true | false | true |
| false | true | true |
| false | false | false |

## 34. Logical NOT (!)

Reverses the Boolean value.

```javascript
let isLoggedIn = true;

console.log(!isLoggedIn);
```

**Output:**

```text
false
```

Another example:

```javascript
let isAvailable = false;

console.log(!isAvailable);
```

**Output:**

```text
true
```

# PART 8: COMMA OPERATOR

## 40. What Is the Comma Operator?

The comma operator (`,`) evaluates multiple expressions from left to right and returns the value of the last expression.

### Example 1: Basic Example

```javascript
let result = (10, 20, 30);

console.log(result);
```

**Output:**

```text
30
```

Explanation:

- First expression: 10
- Second expression: 20
- Third expression: 30
- The last expression is returned.

### Example 2: Using Increment

```javascript
let a = 1;
let b = 2;
let c = 3;

let result = (a++, b++, c++);

console.log("Result:", result);
console.log("A:", a);
console.log("B:", b);
console.log("C:", c);
```

**Output:**

```text
Result: 3
A: 2
B: 3
C: 4
```

Explanation:

- `a++` returns 1, then a becomes 2.
- `b++` returns 2, then b becomes 3.
- `c++` returns 3, then c becomes 4.
- The comma expression returns the last expression's value, which is 3.

**Note:** Commas used to separate function arguments, array elements, or variable declarations are not necessarily uses of the comma operator.

# PART 9: OPERATOR PRECEDENCE

## 41. What Is Operator Precedence?

Operator precedence determines the order in which JavaScript evaluates operators in an expression.

For example:

```javascript
let result = 10 + 5 * 2;

console.log(result);
```

**Output:**

```text
20
```

Why?

Multiplication has higher precedence than addition.

JavaScript evaluates:

```text
10 + (5 × 2)

10 + 10 = 20
```

### Example 2: Using Parentheses

```javascript
let result = (10 + 5) * 2;

console.log(result);
```

**Output:**

```text
30
```

Parentheses are evaluated first.

### Example 3: Multiple Arithmetic Operators

```javascript
let result = 100 - 20 / 2 + 5 * 3;

console.log(result);
```

**Output:**

```text
105
```

Calculation:

```text
100 - 10 + 15

90 + 15 = 105
```

### Common Operator Precedence

| Priority | Operator | Description |
|---|---|---|
| Highest | `()` | Grouping |
| High | `**` | Exponentiation |
| High | `*`, `/`, `%` | Multiplication, Division, Modulus |
| Medium | `+`, `-` | Addition, Subtraction |
| Medium | `<`, `>`, `<=`, `>=` | Relational |
| Medium | `===`, `!==` | Equality |
| Lower | `&&` | Logical AND |
| Lower | `||` | Logical OR |
| Lower | `?:` | Ternary |
| Very Low | `=`, `+=`, `-=` | Assignment |

Note: Operators at the same precedence level are generally evaluated according to their associativity. Exponentiation is right-associative, while most arithmetic operators are left-associative.

# 58. Summary

In this chapter, we learned about JavaScript operators and how to use them in practical programming.

| Operator Category | Operators |
|---|---|
| Arithmetic | `+`, `-`, `*`, `/`, `%`, `**` |
| Increment / Decrement | `++`, `--` |
| Assignment | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `**=` |
| Comparison | `==`, `!=`, `===`, `!==`, `>`, `<`, `>=`, `<=` |
| Logical | `&&`, `||`, `!` |
| Ternary | `? :` |
| String | `+` |
| Typeof | `typeof` |
| Comma | `,` |

### Key Takeaways

1. Arithmetic operators perform mathematical calculations.
2. Assignment operators assign and update variable values.
3. Comparison operators return Boolean values.
4. Logical operators combine multiple conditions.
5. Increment and decrement operators change values by one.
6. Ternary operators provide a short way to write conditional expressions.
7. The `typeof` operator checks data types.
8. Operator precedence determines the order of evaluation.
